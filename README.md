# Cognitive-Load-Aware-Communication-Assistant-and-Adaptive-Summarization  (ONGOING)

Communication barriers significantly affect hearing-impaired and speech-impaired individuals, particularly in real-time conversational settings where processing continuous speech imposes a high cognitive burden. This paper presents an intelligent cognitive load–aware assistive communication system that dynamically adapts conversational output based on user load levels. The proposed system integrates speech-to-text transcription using Whisper, keyword extraction, tone and urgency analysis, and a computational cognitive load model that evaluates conversation complexity. Based on the estimated cognitive load, the system generates adaptive outputs such as full transcripts, condensed summaries, or keyword-focused representations. Furthermore, under high cognitive load conditions, the system provides assistive response suggestions using a large language model. The performance of the system is evaluated using objective metrics such as transcription accuracy, ROUGE score, and information compression ratio, along with subjective human evaluation for response relevance. The results demonstrate improved accessibility and reduced cognitive burden for users in real-time communication scenarios.
